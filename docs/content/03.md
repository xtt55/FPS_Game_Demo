## 本课要解决什么

1. 用自定义 **GameMode** 指定默认生成的角色（Pawn）。
2. 搞清**项目默认 GameMode** vs **关卡游戏模式重载**。
3. 用 **Enhanced Input** 建好 IA / IMC，并把 WASD、鼠标视角、跑步、瞄准映射好。
   **本课不写移动逻辑**——配完后按键没反应是正常的。

---

## 〇、先创建角色蓝图 BP_FPS_Player

> GameMode 要指定「默认用哪个角色」，所以先有角色蓝图，再建 GameMode。

位置：`Scripts/Players`（第 01 课建的文件夹，角色相关蓝图都放这里）。

新建蓝图类 → 父类选**角色（Character）** → 命名 `BP_FPS_Player`，编译保存。

本课只把它建出来并让 GameMode 认识它；移动 / 视角 / 状态逻辑从第 04 课开始在里面写。

---

## 一、GameMode：指定用哪个角色

### 1. 创建 BP_FPS_GameMode

位置：`Scripts/Players/System`（和角色蓝图同级的 System 文件夹，输入资产旁边）。

新建蓝图类 → 父类选**游戏模式基础（Game Mode Base）**，命名 `BP_FPS_GameMode`（加 FPS 前缀，避免和引擎自带 GameMode 搞混）。

打开 `BP_FPS_GameMode`，右侧类设置里把**默认 Pawn 类（Default Pawn Class）**改为 `BP_FPS_Player`，编译保存。

![GameMode 默认 Pawn 类](assets/img/l03-gamemode-default-pawn.png)

此时只是「GameMode 知道要用哪个角色」，**还没有告诉引擎用这个 GameMode**。直接运行仍是默认自由视角。

### 2. 两种指定 GameMode 的方式

| 方式 | 路径 | 作用范围 |
|:---|:---|:---|
| 项目设置（全局修改，推荐） | 项目设置 → 游戏 → 默认模式 | 整个项目 |
| 关卡重载（关卡修改） | 世界场景设置 → 游戏模式重载 | **仅当前关卡** |

全局修改：

![项目设置-默认游戏模式](assets/img/l03-project-settings-gamemode.png)

关卡修改：

![世界场景设置-游戏模式重载](assets/img/l03-world-settings-gamemode.png)

注意：换关卡后关卡重载不会跟着走，所以一般用项目设置做全局默认。

设好后运行：按键/鼠标都没反应 → 说明已切到自定义模式（还没写输入逻辑，**没反应是正常的**）。

## 二、Enhanced Input 资产

位置：`Scripts/Players/System/Input`（之后所有输入资产放这里）。

### 1. 四个输入操作（IA）

| 资产 | 值类型 | 用途 |
|:---|:---|:---|
| `IA_Look` | **Vector2D** | 控制角色视角旋转 |
| `IA_Move` | **Vector2D** | 控制角色移动 |
| `IA_Run` | **bool** | 控制角色是否跑步（只有跑/不跑两种状态） |
| `IA_Aim` | **bool** | 控制角色是否瞄准（只有瞄/不瞄两种状态） |

默认往往是布尔，Look/Move 必须改成 Vector2D。

### 2. 一个输入映射上下文（IMC）

`IMC_FPS_Input`：控制 FPS 游戏的输入总映射表。

在 **Default Key Mappings → Mappings** 中添加 IA_Look、IA_Move、IA_Run 和 IA_Aim（注意点**上面那个 `+`**，下面还有一个长得像的加号，别点错）。

### 3. 各 IA 的按键绑定

**IA_Look**：

- 添加控制：鼠标移动，值为鼠标 XY 2D 轴
- 鼠标移动添加修改器-**否定（Negate）**，避免鼠标向上移动视角向下

![IA_Look 映射](assets/img/l03-imc-ia-look-negate.png)

**IA_Move**：添加 WASD 4 个键盘按键

| 键 | 修改器 | 作用（类比二维坐标系） |
|:---|:---|:---|
| W | 无 | 前进，Y 轴正方向 |
| S | **否定** | 后退，Y 轴反方向 |
| A | **拌合输入轴值（Swizzle）** + **否定** | 换到 X 轴上，且左为负 |
| D | **拌合输入轴值（Swizzle）** | 换到 X 轴上 |

![IA_Move 映射](assets/img/l03-imc-ia-move-wasd.png)

**IA_Run**：左 Ctrl

![IA_Run 映射](assets/img/l03-imc-ia-run-ctrl.png)

**IA_Aim**：鼠标右键

![IA_Aim 映射](assets/img/l03-imc-ia-aim-rightmouse.png)

## 易错点速查

1. 建了 GameMode 却忘了项目设置 / 关卡重载 → 仍是默认视角。
2. 只设关卡重载 → 换图失效。
3. IMC 点错加号（下面那个）。
4. Look/Move 忘改 Vector2D。
5. A/D 漏 Swizzle，或 A 漏 Negate → 左右轴错乱。
6. 本课配完没反应 → **正常**，逻辑在下一课。
