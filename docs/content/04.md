## 本课要解决什么

1. 在 Player 的 `BeginPlay` **激活 Enhanced Input**。
2. 实现 `IA_Move` 水平移动、`IA_Look` 视角旋转。
3. 讲清 **Yaw / Pitch / Roll**，以及移动时**为什么只连 Control Rotation 的 Z（Yaw）**。

---

## 〇、先看懂蓝图：连线和颜色

开始读蓝图前，先记住两类连线：

- **执行线（Execution）**：白色粗线，控制「先干啥后干啥」的顺序流。
- **数据线（Data）**：彩色细线，把一个值传给另一个节点。

细线颜色对照：

| 颜色 | 数据类型 | 本课出现的例子 |
|:---|:---|:---|
| 🔴 红 | 布尔 Boolean | 各 Branch 的判断条件 |
| 🟢 绿 | 浮点 Float | Move X、常量 0.0 |
| 🔵 蓝 | 向量 Vector | Get Forward Vector 的输出 |
| 🟡 黄 | 旋转器 Rotator | Get Control Rotation 的输出 |
| 🟠 橙 | 变换 Transform | （本课没用到） |
| 🟣 紫 | 函数入口/事件 | 函数定义的入口节点 |
| 🔵 深蓝 | 对象引用 Object | Controller、Character Movement 组件引用 |
| ⚪ 自定义色 | 枚举 Enum | E Player State 的取值 |

一句话记忆：**红色是判断题、绿色是数字、蓝色是向量、深蓝是对象**。

## 一、BeginPlay：激活输入映射上下文

![BeginPlay 激活输入链](assets/img/l04-beginplay-input-chain.png)

### 节点逐个解释

| 节点 | 作用 |
|:---|:---|
| **Event BeginPlay**（红色事件节点） | 事件开始入口，游戏一运行就触发一次 |
| **Get Controller** | 获取玩家控制器。Target 为 self，多人游戏会根据 index 获取对应的玩家控制器；表示「谁运行控制谁」 |
| **Cast To PlayerController** | 类型转换。只有真正的玩家（而不是 AI）才会去绑定后续的输入系统 |
| **Enhanced Input Local Player Subsystem** | 增强输入本地玩家子系统，增强输入系统的入口 |
| **Add Mapping Context** | 通过这个引脚关联自定义的输入系统；Mapping Context 设为 `IMC_FPS_Input` |
| **Spawn Weapon** | 调用枪械生成函数（第 10 课模块化后才有，详见[第10课](lesson-10.html)；如果用静态组件直接挂枪则不需要这一节点） |

### 补充：单机简写与多人写法

单机且只有一个玩家的游戏可以用「Get Player Controller，index 恒定为 0」的短写法，表示第一个玩家：

![Get Player Controller index 0](assets/img/l04-get-player-controller-index0.png)

但这是硬编码：本地分屏 / 多人时玩家 2 也会去抢 Index 0 的控制器。`Get Controller`（Target=self）的写法是问「**当前这个角色**的控制器是谁」，各玩家独立，更稳。

## 二、IA_Move：水平移动

![IA_Move 完整图](assets/img/l04-eventgraph-ia-move.png)

### 节点逐个解释

| 节点 | 作用 |
|:---|:---|
| **EnhancedInputAction IA_Move**（红色事件） | 控制角色移动，操控角色在场景中平移。**Triggered** 引脚在键按住时持续触发；**Completed** 引脚在键抬起时触发一次 |
| **Break Vector2D**（纯函数） | 把 Action Value 的 Vector2D 分解为 X 和 Y 分量。也可以不要这个节点，直接右键 Action Value 引脚「分割结构体引脚」，这里只是为了更清晰地展示数据流 |
| **SET Move X / SET Move Y** | 把 X/Y 轴的值存进变量。存成变量后，才能在 Completed 分支把它们设回 0（变量从左侧变量面板拖出，或右键「提升为变量」） |
| **Completed → SET(Move X: 0) / SET(Move Y: 0)** | 松开按键时把变量清零。**必须做**：Triggered 只在按住时跑，松开后变量会卡在最后的值，角色会一直移动 |
| **Get Control Rotation** | 获取玩家角色的控制旋转（鼠标看向哪） |
| **Get Forward Vector / Get Right Vector** | 获取前向/右向向量。注意选**数学→向量**分类下的，不要点到「变换」里的同名项 |
| **Add Movement Input** | 把移动输入应用到玩家角色。World Direction 表示方向，Scale Value 表示速度（接 Move X / Move Y） |

### 工作流

```
按下 WASD → IA_Move Triggered 持续触发
  → Action Value (Vector2D) 拆成 X / Y
  → 存入 Move X / Move Y（供动画系统使用）
  → Get Control Rotation（只取 Yaw）→ Get Forward/Right Vector
  → Add Movement Input（前向 × X，右向 × Y）→ 角色平移
松开 WASD → Completed 触发 → Move X / Move Y 置 0 → 停止输入
```

### 为什么移动只连 Z（Yaw）

| 名称 | 绕哪根轴 | 直觉 |
|:---|:---|:---|
| **Yaw（偏航）** | Z | 左转右转，指南针东南西北 |
| **Pitch（俯仰）** | Y | 抬头 / 低头 |
| **Roll（滚转）** | X | 歪头 |

移动时若把 Pitch/Roll 也喂给 Forward 向量：低头按 W，前进方向会指向地面，越走越慢甚至卡住。

**只连 Z**：告诉引擎「只要面朝东南西北，忽略抬头低头」→ Forward 永远贴地 → W 始终沿地面平面前进。

## 三、IA_Look：视角旋转

![IA_Look 完整图](assets/img/l04-eventgraph-ia-look.png)

| 节点 | 作用 |
|:---|:---|
| **EnhancedInputAction IA_Look** | 控制角色视角旋转（转头），主要是 X/Y 两轴 |
| **Break Vector2D** | 把鼠标 XY 分解成两个分量 |
| **Add Controller Yaw Input** | 控制左右旋转（接鼠标 X） |
| **Add Controller Pitch Input** | 控制上下旋转（接鼠标 Y） |

「鼠标上滑却低头」的修正：不要到处乘 -1，在 **IMC 的 IA_Look** 上加修改器 **Negate** 即可（见[第03课](lesson-03.html)）。

## 易错点

1. Add Mapping Context 接到 Cast Failed 分支上。
2. 用 Index 0 短写法却以为适合所有项目。
3. Forward/Right 点错分类（变换 vs 数学/向量）。
4. Move 时把 Pitch 也连上 → 抬头低头卡移动。
5. 忘了 Completed → 置 0 → 松键后角色一直走。
