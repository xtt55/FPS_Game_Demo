## 本课要解决什么

1. 搭第一人称组件：手臂（骨骼网格体）+ 摄像机 + 枪（骨骼网格体）+ 配件（静态网格体）。
2. 摄像机绑 **Head 插槽**，走路视角跟骨骼颠簸。
3. 自定义摄像机后，用 **Tick + Set World Rotation** 恢复抬头低头。
4. 调小**近剪切平面**，避免枪口被裁切。

## 一、组件层级

`BP_FPS_Player` 的组件树，注意层级关系：

![组件层级](assets/img/l05-component-hierarchy.png)

### 1. 手臂（Arm）

人物手臂，属于**骨骼网格体组件**（要播动画、有插槽，不能用静态网格体）。

设置：

- 缩放：全部为 0.25
- 骨骼网格体资产：添加预设的手臂骨骼
- 动画模式：先用「使用动画资产」套 idle 动作临时看效果；动画蓝图做好后（[第07课](lesson-07-09.html)）改成「使用动画蓝图」

![手臂设置](assets/img/l05-arm-settings.png)

### 2. 摄像机（Camera）

摄像机组件，挂在 Arm 下。

设置：

- 旋转：X 轴旋转 -90 度，不然摄像机视角会倒置
- 缩放：全部为 0.25
- 父项套接字：关联到 **Head** 上，这样才能真实反馈角色走路的颠簸感
- 摄像机选项-**使用 Pawn 控制旋转：取消勾选**，这样奔跑状态下摄像机就能随着角色晃动，增加枪械游戏的手感和沉浸感

![摄像机设置](assets/img/l05-camera-settings.png)

### 3. 枪（方法一：直接挂载组件）

> 这是早期做法。第 10 课会把枪拆成独立蓝图（方法二），届时这里的 Gun 组件会被删掉。

枪，属于**骨骼网格体组件**：

- 骨骼网格体资产：添加预设的枪骨骼
- 要播放的动画：套用 idle 动作，和手臂保持一致
- 当动画做好后，需要使用动画蓝图 `ABP_VIRTUL`

![枪设置](assets/img/l05-gun-settings.png)

#### 配件：枪管 / 弹匣 / 枪托

配件属于**静态网格体组件**（非通用知识点，属于枪械骨骼制作时的零件）。

注意：需要设置好配件的父项套接字，否则会飘在半空中；如果设置了父项还飘移，把位置和旋转重置为 0。

## 二、Tick 驱动 Arm 世界旋转（恢复上下看）

### 为什么要多这一步

第 04 课的 Look 蓝图**仍然要留着**，两课是接力，不是替换：

| 步骤 | 在哪 | 干什么 |
|:---|:---|:---|
| ① | 第04课 `IA_Look` | 鼠标 → Add Controller Yaw/Pitch Input，把「想看哪」写进 **Controller 旋转** |
| ② | 本课 `Event Tick` | 读 Control Rotation → Set World Rotation 到 **Arm**，把变化同步给手臂/枪/相机 |

- **没自定义 Camera 时**：引擎塞默认摄像机，大致跟着控制器转，所以上下看「好像只靠①就够」。
- **有了自定义摄像机之后**：引擎不再代管默认摄像机；必须再加②，把 Controller 的变化接到 Arm 上，否则会出现左右还行、上下没反应等问题。

一句话：① 负责「算朝向」，② 负责「把朝向接到 Arm」。

### 节点逐个解释

![Tick 驱动 Arm](assets/img/l05-tick-arm-world-rotation.png)

| 节点 | 作用 |
|:---|:---|
| **Event Tick** | 每帧更新，视角才能连续跟手。自定义摄像头后，角色的上下转向会受限，需要 Tick 来实现平滑转向 |
| **Get Control Rotation** | 读第 04 课 Look 写进 Controller 的朝向 |
| **Arm**（变量） | 人物的手臂（骨骼网格体组件引用） |
| **Set World Rotation** | 设置**世界旋转**，使手臂跟随视角旋转。Target 接 Arm |

注意：连线是连接 **Y 轴（Pitch）和 Z 轴（Yaw）**，实现角色的上下和左右转向；**X（Roll）不连**，不要歪头。

### 为什么 Target 是 Arm，不是 Camera？

层级是 Arm → Camera / Gun，相机还绑在 Arm 骨骼的 **Head 插槽**上。转 Arm = 整套第一人称组件一起转；相机既跟 Arm，又跟头部插槽，走路时才会有真实晃动。

### 为什么用 World Rotation，不用 Relative？

Relative 会叠在父级/插槽本地空间上，容易和 Head 插槽搅在一起。World = 「Arm 在世界里就朝控制器这个方向」，和 Look 语义一致。

### 和 Walk「只连 Z」别混

| | Walk（移动） | 本图（看） |
|:---|:---|:---|
| 目的 | 贴地走 | 手臂/相机跟着看 |
| 用哪些轴 | 只要 **Yaw(Z)** | 要 **Pitch(Y) + Yaw(Z)** |
| 原因 | 抬头时别往天上飞 | 看就是要能抬头低头 |

## 三、近剪切平面（Near Clip Plane）

项目设置搜索 near clip，**设置为 0.1**。

作用：决定摄像机能看到的最近距离，任何距离摄像机小于这个数值的物体都会被直接切掉。主要是为了防止角色离墙太近时遮挡视线；默认值偏大时还会把太近的枪口/手臂裁掉。改完**重启引擎**生效。

![近剪切平面](assets/img/l05-near-clip-plane.png)

另外可把 Arm 上移到胶囊体横线附近（正常人眼高度）。

## 易错点

1. Arm/Gun 误用静态网格体 → 无骨骼、难挂插槽/动画。
2. 点成「电影摄像机」（应选普通摄像机组件）。
3. Tick 用了 Relative Rotation。
4. Near Clip 改完不重启。
5. 配件不指定父项套接字 / 不归零 Transform。
6. Camera 的「使用 Pawn 控制旋转」忘关 → 奔跑时没有预期晃动。
