## 本课要解决什么

1. 给鼠标视角增加一个**基础灵敏度系数**（`MouseSensitivity` 变量，默认 `0.7`），让转头速度可调。
2. 不同状态下使用**不同的灵敏度倍率**：Idle / Walk / Run 保持 `1.0`，Aim 时降到 `0.4`（瞄准时更稳、更精确）。
3. 把原来的 `IA_Look` 直接连 `Add Controller Yaw/Pitch Input`，改成**先乘灵敏度再输入**。
4. 学习用**纯函数（Pure）**封装一个“根据当前状态返回倍率”的小工具。

---

## 第一步：新建 MouseSensitivity 变量

在 `BP_FPS_Player` 的变量列表里新建一个浮点变量 **`MouseSensitivity`**：

- 类型：**float（浮点）**
- 默认值：**`0.7`**
- 作用：全局基础鼠标灵敏度，后续所有视角输入都要先乘它

![MouseSensitivity 默认值 0.7](assets/img/l13-mousesensitivity-default.png)

> 为什么默认 `0.7`？工程里试出来的手感值。以后可以在运行时暴露到设置菜单让玩家自己改。

---

## 第二步：新建纯函数 UpdateScoreSensitivity

新建一个函数，命名为 **`UpdateScoreSensitivity`**（函数名随项目实际命名，这里是笔记里的名字）。

### 输出变量

- 名字：**`OutSensitivity`**
- 类型：**float**

![函数体内部](assets/img/l13-updatescore-function-select.png)

### 函数体：按状态选倍率

```
E_PlayerState
  ↓
Select（枚举选择）
  ├ Idle  → 1.0
  ├ Walk  → 1.0
  ├ Run   → 1.0
  ├ Aim   → 0.4
  ↓
Return Node：Out Sensitivity
```

- **Select** 节点：根据枚举值输出不同的浮点常数。
- `Idle / Walk / Run` 都是 `1.0`，意思是平时转身速度就是“基础灵敏度 × 1”。
- `Aim` 是 `0.4`，意思是瞄准时转身速度变成“基础灵敏度的 40%”，更稳。

### 关键设置：把函数设为“纯函数”

![勾选纯函数](assets/img/l13-updatescore-pure.png)

在函数细节面板里勾选 **纯函数（Pure）**。

- 纯函数**没有白色执行引脚**，只有输入 / 输出数据引脚。
- 它会像 `Break Vector 2D`、`Get` 变量一样，在蓝图需要它的值时自动求值。
- 适合这种“只读状态、返回一个数”的小计算， graph 更干净。

---

## 第三步：修改 IA_Look 视角输入

回到 `BP_FPS_Player` 的 `IA_Look` 事件，把原来直接接 `Add Controller Yaw/Pitch Input` 的 Action Value 改成**先乘灵敏度**。

### 最终链路

![IA_Look 缩放后的视角输入](assets/img/l13-ia-look-sensitivity.png)

```
EnhancedInputAction IA_Look
  ├ Triggered（执行触发）
  └ Action Value（Vector2D）
       ↓
    Break Vector 2D
       ├ X ──→ ×（乘法）──→ Add Controller Yaw Input   （左右转）
       └ Y ──→ ×（乘法）──→ Add Controller Pitch Input （上下看）
```

每个 `×` 乘法节点有三个输入：

| 输入 | 含义 |
|:---|:---|
| `X` 或 `Y` | 鼠标 / 手柄在这一帧的原始二维输入 |
| `Mouse Sensitivity` | 基础灵敏度变量（默认 0.7） |
| `Out Sensitivity` | 纯函数 `UpdateScoreSensitivity` 返回的状态倍率（Aim 时 0.4） |

### 输出接线

- **X 分量** 乘完后接 **`Add Controller Yaw Input`** 的 `Val`（左右转头）。
- **Y 分量** 乘完后接 **`Add Controller Pitch Input`** 的 `Val`（上下抬头 / 低头）。

> 如果你帧率很高或鼠标 DPI 很高，也可以把 `Mouse Sensitivity` 默认调小；如果感觉太肉就调大。最终有效的 Aim 灵敏度 = `MouseSensitivity × 0.4`。

---

## 数据流一句话总结

```
最终视角输入 = 原始输入 × MouseSensitivity × UpdateScoreSensitivity()
             = 原始输入 × 0.7 × (Idle/Walk/Run=1.0 或 Aim=0.4)
```

- 平时：`0.7 × 1.0 = 0.7`
- 瞄准时：`0.7 × 0.4 = 0.28`

这样瞄准时镜头移动会明显变慢，更容易精确对准目标。

---

## 易错点速查

1. `UpdateScoreSensitivity` 没勾 **纯函数** → 节点会多一个执行引脚，没法直接塞到 `Add Controller ... Input` 的 `Val` 里。
2. `Mouse Sensitivity` 默认值为 `0` → 鼠标怎么动都没反应。
3. 只乘了 `Mouse Sensitivity` 没乘 `Out Sensitivity` → Aim 时不会变慢，失去瞄准精度优势。
4. `Select` 里 `Aim` 的倍率设反了（比如设成 2.0）→ 瞄准时镜头反而飘得更快。
5. `Add Controller Yaw Input` 和 `Pitch Input` 接反（X 接 Pitch / Y 接 Yaw）→ 鼠标上下动变成转头，左右动变成抬头。
6. 直接在 `IA_Look` 的 Action Value 上乘负数想“修正鼠标反向” → 应该在 **IMC 的 IA_Look** 上加 `Negate` 修改器（见第 03 课），不要在 Event Graph 里到处乘 -1。
